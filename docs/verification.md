## 模型验证边界

完整 Agent 工具循环使用真实 OpenAI Python SDK 与 Agents SDK，但模型 HTTP 服务被测试替身替代：第一轮返回喂食工具调用，第二轮返回中文回答。测试检查两次预算、正确的 completion 参数、工具结果、事件与重复执行保护。该检查证明协议路径和业务闭环，不证明真实模型质量或代理兼容性。

向量测试在真实 pgvector 列上写入受控向量，验证语义候选路径、距离排序和用户归属过滤。没有配置真实 Embedding 密钥，因此不把受控向量视作真实中文语义能力评估。

当前没有真实对话或 Embedding 密钥，未发起真实外部模型请求。对话、模型记忆提取和摘要仍需配置服务联调；基础养成、手动记忆和词法检索可独立使用。

## 评估观察

样例报告保存在忽略目录 `.local/recall-report.json`。关键词召回可以覆盖精确字段和部分词面改写；纯语义改写样例仍可能无结果。这是后续混合召回对比应验证的内容，不用同义词硬编码来冒充向量效果。

当前样例集很小，不报告论文级准确率或用户体验改善。正式实验需要扩充、冻结独立测试集，接入真实模型，标注回答依据并进行真实用户研究。

## 已知限制与实施调整

- Tailwind 升级到 4，Vitest 升级到 5，并更新锁文件中的兼容依赖；旧 Tailwind 配置改为 PostCSS 新插件。
- 二维反馈复用原有插画及 CSS 动作，尚未新增完整逐帧素材，图片仍较大。
- 第一版采用精确向量扫描，未作大规模并发或近似索引基准。
- 摘要是带来源的近期窗口摘要。超过后台预算的材料保留原文并跳过，不声称完整覆盖历史。
- 引用校验可以检查原文依据，但不能完全消除模型提炼错误；提供来源及用户纠正机制。
- 普通遗忘会保守排除同源事实和关联回答，可能同时减少其他上下文信息。
- Dockerfile、Compose 和 Nginx 配置已提供，宿主缺少 Docker，因此容器镜像尚未实际构建验证。
